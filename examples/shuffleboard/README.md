# Shuffleboard

Run `npm run shuffleboard` from the repository root and open
[Shuffleboard on port 3400](http://localhost:3400/). To pair a phone, open
the game at an address both devices can reach, choose **Connect phone**, and
scan the QR code. Touch controls work over local Wi-Fi.

Hold the phone upright and tap **Play/Pause** to start. Move your finger in
the touch area to line up the puck, then push it toward the dashed line. The
puck starts gliding as soon as it crosses that line, even with your finger
still down. A faster push sends it farther. It scores 1, 2, or 3 when it
stops with the entire puck across the corresponding scoring line.

## Phone check

1. Try two upward strokes that travel roughly the same distance at different
   speeds. The faster push should send the puck farther.
2. Pull backward and sideways before pushing. The puck should follow both
   directions. Push across the dashed line and keep your finger down to see
   the puck start gliding. Lifting should add no extra boost.
3. Lock the phone mid-stroke. The game should pause and return the puck to
   its starting position. Unlock the phone and tap **Play/Pause** to continue.

You can also test from the computer. Click **Start**, then push upward with
the mouse on the board.
